# Third-party components in NoteGran

NoteGran is MIT licensed (see the LICENSE file). Its plugins contain the components below as well, each under its own license, whose full text follows. Versions are the ones pinned in this repository. Every binary package includes this file.

| Component | Version | License | Used for |
|---|---|---|---|
| [CLAP](https://github.com/free-audio/clap) | 1.2.10 | MIT | the plugin API headers |
| [DPF (DISTRHO Plugin Framework), Unlikelyware's fork](https://github.com/erickampman/DPF) | 10c859cf | ISC | the plugin window (its DGL library only) |
| [pugl, Unlikelyware's fork](https://github.com/erickampman/pugl) | 0d8df03c | ISC | windows and events, inside DPF |
| [NanoVG, with fontstash](https://github.com/memononen/nanovg) | in DPF | zlib | drawing the user interface, inside DPF |
| [stb_image and stb_truetype](https://github.com/nothings/stb) | in DPF | Public domain (or MIT) | image and font loading, inside NanoVG |
| [DejaVu Sans font](https://dejavu-fonts.github.io/) | in DPF | Bitstream Vera / DejaVu (free) | the interface text, embedded by DPF |

Also from Unlikelyware, under the same MIT license: uw-core.
